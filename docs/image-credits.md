## What the licenses require

- **CC0:** no conditions. We credit the photographer anyway.
- **CC BY 2.0:** credit the author, link the license, and note that changes were made. Commercial use is allowed.
- **CC BY-SA 3.0:** the same as CC BY, and the modified photo itself stays under CC BY-SA 3.0. This applies only to the image file, not to the rest of the website. Commercial use is allowed.

Credit lines on the site show the author, license and source for each photo. This page records the changes. Creative Commons licenses don't grant rights to any people, trademarks or private property shown in a photo. These photos show public gardens and contain no identifiable people.

## Adding or replacing a photo

1. Use only your own photos, or photos with a license that allows commercial use (CC0, CC BY, CC BY-SA, the Unsplash License, the Pexels License). Avoid "NonCommercial" (NC) and "NoDerivatives" (ND) licenses.
2. Add the file under `src/assets/img/`, add or update the item in `content/gallery.json` with a complete `credit`, and add a row to the table above.
3. Run `npm run check`. The build stops if an inspiration photo is missing its file, alt text or credit, and a test checks that every photo appears in this file.
