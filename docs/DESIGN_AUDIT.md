# Design audit and professional redesign spec

**Site:** https://landscapemvp.netlify.app (built from `main`, October 2026)
**Pages audited:** Home, Services & Projects, South Florida Plants, Contact, Privacy, Thank-you, 404
**Goal:** move the site from "playful and vibe-coded" to "quiet, professional South Florida landscape studio", without changing content, the inquiry workflow or the brand voice ([brand-voice.md](brand-voice.md)).

> **Status (October 2026): applied.** Decisions: licensed Bonnet House photo in the hero; licensed real plant photos for the guide; terracotta kept only for link hover. The sections below remain the reference for why the site looks the way it does.

This document is written for Claude Code. Each recommendation names the file and selector to change. Apply it in the order given in [§6 Implementation order](#6-implementation-order).

> **On whitespace.** The brief asks for "more whitespace", but the last round asked for less negative space. Both are right once you separate two things. Keep the **space between sections** tight (it was already reduced 30%). Add **space inside components**: fewer elements per screen, wider margins around text, no decorative clutter. The page feels calmer because there's less in it, not because the gaps are bigger.

## 1. Audit findings

Severity: **High** = makes the site look amateur or AI-generated; **Med** = noticeably weakens it; **Low** = polish.

### 1.1 Illustration style (High)

| Finding | Where | Evidence |
|---|---|---|
| Flat cartoon scenes (round lollipop leaves with red veins, spiky palms, potted plants) set the tone of the whole site | Hero, 6 service cards, 9 plant cards, Robert's portrait placeholder | 12 illustrations on Home, 9 on Plants, 6 on Services (`/img/art/*.svg`, generated by `src/build/illustrations.mjs`) |
| Real photos sit next to cartoons, so neither looks intentional | Home: inspiration mosaic (4 real photos) directly below 6 cartoon service cards | Mixed media on one page |
| The arch frame, decorative ring and radial glow add ornament with no meaning | `.hero-art .arch`, `.hero-art::after`, `.hero::before` | Three decorative layers in one hero |
| Plant "portraits" are stylized drawings, so the plant guide can't teach identification | `plant-card .card-media` | A croton drawn as colored triangles |

### 1.2 Animation and interaction (High)

| Finding | Where |
|---|---|
| Cards fade and slide up as you scroll: the clearest "template site" signal | `.reveal` in `site.css`, the IntersectionObserver in `src/assets/js/site.js` |
| Images zoom on hover (cards 600ms, mosaic 700ms) | `a.card:hover .card-media img`, `.mosaic-item:hover img` |
| The arrow inside every button slides right on hover | `.btn:hover .arrow` |
| Buttons press down on click; the menu icon morphs into an X | `.btn:active`, `.nav-toggle-icon` |
| Hover shadows appear on cards | `a.card:hover { box-shadow }` |

There are about 15 moving or animated effects in total. A professional studio site needs about two: color change on hover, and the form's loading spinner.

### 1.3 Repeated "generated" patterns (High)

| Pattern | Count | Why it reads as vibe-coded |
|---|---|---|
| Uppercase terracotta label + decorative line above every heading | 7 on Home, 6 on Plants, 5 on Services | The same three-part opener (label, serif headline, grey intro) on every section |
| Cards for everything | 31 card elements on Home, 32 on Services, 27 on Plants | Content that should be a list or plain text is boxed |
| Pill-shaped buttons, chips and badges | `--radius-pill` used 6 times; chips on gallery and plant cards | Pills read as app UI, not a design studio |
| Soft 20px corners on most surfaces | `--radius-lg` used 12 times | Rounded, toy-like feel |
| Dots before list items | `.hero-note li::before`, `.badge::before`, mobile nav | Ornamental noise |
| Three heavy dark-green blocks per page | Hero, CTA band, footer | Repetitive; each loses impact |

### 1.4 Typography (Med)

- The headline type is strong (Newsreader), but italic is overused: the hero phrase, Robert's greeting, review quotes, the signature, step numerals. Italic should be rare to keep its effect.
- Too many type styles in use: three uppercase label variants (`.eyebrow`, `.card-eyebrow`, `.info-list dt`), plus italic numerals and badge text. Aim for one label style.
- Body text and the intro paragraphs under headings (`.lede`) are nearly the same size (17 vs 20px) with the same grey, so the hierarchy is soft.
- Section headings (h2) step straight from 64–81px page titles down to about 38px; card headings (h3, 22–26px) look similar to the intro paragraphs.

### 1.5 Color (Med)

- **Blush** (`#E3B7A6`) as the hero italic and main button reads pink and playful against deep green. Replace it with a grounded limestone tone.
- **Terracotta** is spread thin: labels, required-field asterisks, step numerals, the review quote mark, the hero ring. Restrict it to one job, or drop it.
- Sage and ivory alternate in section backgrounds on almost every section. Banding everything removes the contrast that should mark important sections.

### 1.6 Layout and component hierarchy (Med)

- **Home is too long and too boxed:** hero → Meet Robert → 6 service cards → mosaic → 4 steps → 3 plant cards → (reviews) → CTA band → footer. Too many equal-weight sections.
- **Services on Home** repeat the full Services page in cartoon cards. A compact two-column text list would do the same job in a third of the height.
- **Plant cards on Home** duplicate the plant guide and use cartoons. Replace them with one line and a link, or with 3 real plant photos.
- **The CTA band** appears on every page in the same dark style as the hero, so it competes with it.
- **The gallery:** each card shows a label tag, category label, title, caption, location and credit, which is heavy for a browsing grid.

### 1.7 Responsiveness (Low; mostly resolved)

The responsive QA in [responsive-spec.md](responsive-spec.md) holds: no sideways scrolling from 320 to 2560px, the full hero on the first screen of common laptops, and 1/2/3-column grids. The changes below keep those rules. Two small items remain:
- At 640–895px the stacked hero illustration still pushes the next section a full screen down. With a photo in a plain frame this matters less (see §2.2).
- On phones, Robert's portrait (about 340×425px) comes before his story, which delays the text. Cap it at 70% width on phones.

### 1.8 Accessibility (Low)

Contrast passes (`tests/site.test.mjs`), focus is visible, and motion respects the reduced-motion setting. To keep:
- Any new photo needs real alt text. Any line art is decorative: `alt=""` or `aria-hidden="true"`.
- Rectangular buttons must stay at least 44px tall.
- Removing the scroll-reveal also removes a source of content invisible to some screen-reader and print paths.

## 2. Professional design recommendations

### 2.1 Visual direction: "Field notes from a landscape studio"

Quiet, architectural and photographic. Think a landscape architect's portfolio, not a SaaS landing page.

| Replace | With |
|---|---|
| Cartoon SVG scenes | **Real photography first.** Robert's own project photos, as he takes them. Until then, licensed photos (the 8 already in the repo, plus CC0 plant photos for the guide), always credited and labeled as inspiration where they aren't his work. |
| Decorative illustration where no photo fits | **Single-weight botanical line drawings:** a 1.25px stroke in `--color-leaf-900` at 70% opacity, no fills, no outlines with color, drawn from real leaf shapes (seagrape, coontie, sabal frond). Use them sparingly, at most one per page. |
| Arch frame + ring + glow | A plain rectangle with a 4px radius, or no frame at all |
| Pill buttons | Rectangular buttons with a 4px radius, medium weight, letter-spacing 0.01em |
| Chips, badges with dots | Plain small text separated by a middle dot ("Florida native · Full sun") |
| Section labels with lines | Labels only on page headers; section headings stand alone |

### 2.2 Revised layout structure

**Home (6 sections, from 8):**

1. **Hero:** keep the bold deep-green band and the three-line headline. Swap the cartoon arch for one **real photograph** in a plain 4:5 frame (interim: `florida-friendly-bonnet-house-desert-garden`, captioned "Inspiration · Bonnet House, Fort Lauderdale"). Remove the glow and the ring. One primary button and one text link ("See design ideas →") instead of two pill buttons.
2. **Meet Robert:** keep it. The placeholder becomes a neutral sand rectangle with a fine-line seagrape leaf and the caption until his photo exists.
3. **Services:** a **two-column list**, not cards. Each item is a title, one sentence and an arrow link. No images.
4. **Design ideas:** keep the photo mosaic (it's the best part of the site). Drop the label chips on tiles; keep title + category in one line.
5. **How it works:** 4 steps in a single row with plain numerals ("1  Tell me about your space"), no italic numerals and no top borders.
6. **Closing invitation:** a **light** band (sand background, dark text) with one button, so the deep-green hero stays the only dark block above the footer.

Remove the "Plants that thrive in Broward" cards from Home; add one line in How it works or the closing invitation linking to the plant guide.

**Services & Projects:** keep the alternating rows but use photos (the existing inspiration photos fit each service), with a 3:2 plain frame and no rounded mat. In the gallery, remove the per-card tag; show the "Landscape design inspiration" notice once above the grid, and move the credit into a quieter caption line.

**South Florida Plants:** plant cards get real plant photos (CC0 from Wikimedia Commons; download and license check needed) or, as an interim, **no image**: a typographic card with name, scientific name and facts. The plain version looks more like a professional reference than a cartoon.

**Contact:** fine as is. Make the sidebar cards flat (no rounded mats), and move the "What happens next" list into plain text.

### 2.3 Spacing rules

| Token | Now | Recommended | Use |
|---|---|---|---|
| `--section-space` | `clamp(3rem, 2rem + 3.5vw, 5rem)` | keep | between sections |
| Section head → content | `--space-6` (32px) | `--space-5` (24px) | heading to grid/list |
| Card padding | 24px | 20px, or no card | |
| Grid gap | 24px | 32px horizontal / 40px vertical for photo grids | photos need air; text grids stay 24px |
| Paragraph measure | 38rem | 34rem for intros, 38rem for body | keeps intros tight under headings |

### 2.4 Typography scale

| Role | Font | Size | Weight / style |
|---|---|---|---|
| Hero h1 | Newsreader | `clamp(2.75rem, 1.5rem + 3.6vw, 5.25rem)` (keep) | 400, roman; italic for the last phrase only |
| Page h1 | Newsreader | `clamp(2.25rem, 1.6rem + 2.4vw, 3.75rem)` | 400 |
| h2 | Newsreader | `clamp(1.875rem, 1.4rem + 1.6vw, 2.75rem)` | 400 |
| h3 | Figtree (not serif) | 1.125–1.25rem | 600; separates card titles from headings |
| Intro (`.lede`) | Figtree | 1.1875rem | 400, `--color-ink` (not muted) |
| Body | Figtree | 1.0625rem / 1.65 | 400 |
| Label (one style) | Figtree | 0.75rem, 0.12em tracking | 600, uppercase, `--color-ink-muted`; page headers only |
| Caption / credit | Figtree | 0.8125rem | 400, `--color-ink-muted` |

Italic only for the hero phrase and Robert's signature.

### 2.5 Color palette adjustments

| Token | Now | Recommended | Note |
|---|---|---|---|
| `--color-blush` | `#E3B7A6` | **retire** | |
| `--color-limestone` (new) | — | `#E4D8C3` | Hero italic + hero button on deep green (contrast 9.3:1 with `#1F3529`) |
| `--color-terracotta` | `#B8694C` | **one job:** link hover underline, or retire | |
| `--color-sand` | `#EDE6D8` | keep | Closing band, photo placeholders |
| Section tints | ivory + sage alternating | ivory only, for **one** emphasized section per page | Most sections on the canvas color |

Deep green is used for the hero and footer only.

### 2.6 Animation

| Keep | Remove |
|---|---|
| Color and underline changes on hover (150ms) | Scroll-reveal fade-ups (CSS + JS) |
| Form spinner | Image zoom on hover |
| `prefers-reduced-motion` handling | Arrow nudge, button press, menu icon morph |
| | Card hover shadows and lift |

### 2.7 Calls to action

- **One primary style:** deep green rectangle on light backgrounds, limestone rectangle on dark.
- **Secondary = text link** with an arrow and underline, not an outlined pill.
- Keep the labels exactly: "Start Your Project" (site-wide) and "Tell Me About Your Project" (Robert's section). Don't add more CTAs; reduce "Ask about [service]" links on the Services page to one CTA per section.

### 2.8 Navigation

- Keep the sticky header, but use a solid canvas background without the blur effect, and a 1px bottom border always visible.
- Replace the leaf in a filled circle with the fine-line seagrape mark, or drop the mark entirely for a text wordmark only.
- Header CTA: a rectangular button, height 40px.
- Mobile menu: plain "Menu" / "Close" text that switches, without the animated icon.

### 2.9 Footer

- Two columns on desktop (brand + short statement | links and contact), one on phones.
- Remove the repeated "Send a project inquiry" link (the header CTA covers it).
- Use a smaller, lighter wordmark in the footer.

### 2.10 Component consistency rules

1. **Radius:** 4px everywhere (buttons, inputs, photos, cards). The only exception is the 0px full-bleed hero.
2. **Borders:** 1px `--color-stone`; no shadows anywhere.
3. **Cards** only for things a person compares side by side (gallery photos, plant profiles). Lists of links aren't cards.
4. **One label style**, used only above page titles.
5. **One accent per surface:** deep green on light, limestone on dark.
6. **No ornaments:** no decorative rings, glows, dots, rules beside labels or quote marks larger than the text.

## 3. Responsive specification

The breakpoints and containers in [responsive-spec.md](responsive-spec.md) stay; the additions are marked **new**.

| Breakpoint | Width | Behavior |
|---|---|---|
| base | 0 | One column; text before images; Robert's portrait capped at 70% width (**new**) |
| sm | 40em / 640px | 2-column lists and grids; hero photo capped at 22rem while stacked (**new**: was 24rem) |
| md | 56em / 896px | Hero 1.25fr / 0.75fr; Meet Robert side by side; services list in 2 columns (**new**) |
| nav | 60em / 960px | Full navigation |
| lg | 64em / 1024px | 3-column photo grids; steps in a 4-column row (**new**) |
| xl | 90em / 1440px | Container 80rem |
| 2xl / 3xl | 120em / 150em | Root type 112.5% / 125% |

| Rule | Value |
|---|---|
| Containers | `--container: 72rem` (80rem at xl); text blocks `max-width: 38rem`; intros `34rem` |
| Gutters | `clamp(1rem, 4vw, 2.5rem)` |
| Fluid type | the §2.4 scale; never below 16px body |
| Images | `object-fit: cover`; aspect ratios 4:5 (hero, portrait), 3:2 (services, plants), 4:3 (gallery); width/height attributes always set; WebP 480/800 with `srcset` |
| Grids | explicit 1/2/3 columns (never auto-fill); text lists 1/2 |
| Extended screens | content scales with the root size; photos may grow, text measure never exceeds 38rem |
